# Full Stack WEB Development

A collection of lecture examples, exercises, and small practice projects created while learning full-stack web development.

## Topics

- HTML and CSS
- Bootstrap
- JavaScript
- Node.js

## Repository layout

- `first-lesson/` - introductory JavaScript examples
- `Html-css 1-11 lectures/` - HTML and CSS lecture exercises
- `Bootstrap/` - Bootstrap lecture exercises
- `Javascript/` - JavaScript examples and exercises
- `Node.js/` - Node.js lecture examples
- `project/` - the [Ravensbrew](https://github.com/MRamiko/Ravensbrew) repository, included as a Git submodule

## Working with the examples

Most examples are standalone. Open an `.html` file in a browser to view a web page, or run a Node.js example from a terminal with `node path/to/file.js`.

To clone this repository and its submodule:

```sh
git clone --recurse-submodules https://github.com/MRamiko/Full-Stack-Web-Development.git
```

If you already cloned without submodules, initialize them with:

```sh
git submodule update --init --recursive
```
